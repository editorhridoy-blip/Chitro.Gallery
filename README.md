## Publish on GitHub Pages
1. Create a new repository on GitHub, e.g. `chitro-gallery`.
2. Upload `index.html`, `style.css`, `script.js` and the `assets` folder.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Save. GitHub will provide the live website address.
